## Reproduction and evidence

- `npm run test:ui`: basic navigation plus workflow journeys using a real Firefox browser, local Vite, and a local HTTP fixture. Requires `firefox` and `geckodriver` on PATH; no extra npm library or remote authentication is required.
- `node --test scripts/ui-contract.test.mjs`: existing UI contracts.
- `npm run build`: TypeScript and production bundle.
- `PYTHONPATH=.venv/lib/python3.12/site-packages:backend/src:scripts ../switchyard/.venv/bin/python -m unittest discover -s backend/tests -v`: full backend suite, 147 tests passed. This checkout's `.venv` supplies Mimesis; the existing sibling interpreter supplies the other installed test/runtime packages. No packages were downloaded and no registry configuration was changed.
- Python compilation and `git diff --check` pass.

Browser evidence is generated under `.run/workflow-evidence/`: `results.json`, FHD/4K stage screenshots, editor/review screenshots, and separate connection/metadata/permission/timeout failure screenshots. The directory is intentionally ignored by Git. Backend test output is saved in `.run/workflow-backend-tests.log` for this validation.

## Certification boundary

The frontend ran in a real browser against controlled HTTP responses; the HTTP backend and local generators ran separately with fake Databricks SDK responses. Local generator execution is covered by the backend suite, while UI previews use deterministic fixture values. Simulated Apply/Start clicks never connect to Databricks or execute DDL/publication. Real DEV DDL, effective grants, warehouse startup, cloud storage and publication are **not live-certified** by this work. No PROD records, schema changes or profiling were used.
